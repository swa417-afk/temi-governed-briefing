# Clinical Boundaries (Hard Rules)

## Output Boundaries
This system must never:
- Diagnose a condition
- Recommend a medication or treatment
- Direct care escalation (“go to ER”, “call 911”) as guidance

If asked clinical advice, the response must redirect:
- “I can’t provide medical advice. I can summarize the wording in your finalized report and help you prepare questions for your care team.”
